Retrieval invariant

A claim is "in play" only when both hold:

status = 'active' AND excluded_from_synthesis = 0

status tracks supersession (a rerun replaced it). excluded_from_synthesis tracks human rejection (/ref:verify ... reject). Independent axes — check both.

Stable IDs across reruns — three cases

Content hashPrior claims at same locatorResult
Matches—Keeps existing claim_id. Nothing new.
No matchExactly one, unconsumedNew claim_id + supersedes; old flips to status: superseded + superseded_by, kept in registry.
No matchZero or severalNew claim_id, no supersession asserted.

claim_registry.json keeps every claim ever committed — nothing is ever deleted, only marked superseded.
