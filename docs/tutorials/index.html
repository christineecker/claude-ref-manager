How the tutorials are written

  • Examples use fictional papers whose PMIDs start with 99, outside PubMed's range. That way no real paper is ever described with invented findings.
  • Blocks labelled output from a scratch library come from running the plugin's scripts against a throwaway library. Blocks labelled illustrative output need PubMed, the network, Papers.app, or a subagent, and follow the output format in the script source.
  • Each command name links to its entry in the command reference.
